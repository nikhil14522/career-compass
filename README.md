# Career Compass 🧭

AI-powered career and college guidance for Indian students — assessment, RIASEC
matching, 57 careers, 209 colleges, 33 exams, personalised roadmaps, mentor Q&A,
and a parent trust layer.

**Demo sign-in:** `student@demo.cc` (any password) — the OTP code appears on screen.

Runs as a single Node.js file: `npm install && npm start`
