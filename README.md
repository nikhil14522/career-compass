# Career Compass 🧭

Career and college guidance for Indian students — 15-minute psychometric
assessment, explainable RIASEC career matching, 57 careers, 321 colleges
(93 NIRF-2025 ranked), 33 exams, personalised roadmaps, mentor Q&A, and a
parent trust layer. **Everything is free — no paid plans, no commissions.**

**Demo sign-in:** `student@demo.cc` / `demo1234` (fully worked profile:
assessment, matches, roadmap). Also: `parent@demo.cc` / `demo1234`,
`mentor@demo.cc` / `demo1234`. Or create your own account — sign-up is open.

Runs as a single Node.js file: `npm install && npm start`
(needs Node 22+ — see .nvmrc / Dockerfile).
